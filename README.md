# Eviden

**Know your fit. Prove your edge.**

Eviden 是一个 evidence-based 求职匹配与投递策略 Web App。用户导入简历并输入目标 JD 后，系统会从岗位匹配、证据强度、能力缺口、简历表达和投递优先级等维度，生成可解释、可执行的求职建议。

## 当前版本

当前版本已完成 V1 产品闭环，并接入真实 AI、用户账号和云端数据存储。

核心能力：

1. **岗位分析**：结合简历与 JD 生成匹配评分、证据地图、关键缺口和行动建议。
2. **岗位筛选**：并行比较多个岗位，给出适配度排序和投递优先级。
3. **简历优化**：围绕目标岗位生成有证据边界的改写建议和 HR 开场表达。
4. **历史报告**：保存并恢复岗位分析、筛选和简历优化结果。
5. **投递管理**：管理岗位状态、下一步行动、跟进截止日和活动记录。
6. **Evi 助手**：读取当前页面与投递上下文，提供解释、查询和受控操作建议。
7. **云端同步**：账号、简历、报告和投递记录按用户隔离存储并支持跨会话恢复。

## 产品定位

Eviden 不是单纯的“AI 改简历工具”，而是一个帮助求职者判断岗位是否值得投、应该怎么投，以及如何用证据证明自己匹配的申请策略工作台。

核心方法：

```text
Claim → Evidence → Gap → Action
```

当前版本优先保持功能聚焦：完成从岗位判断、材料优化到投递跟进的核心闭环，不继续堆叠一级功能入口。

## 后续规划

以下能力属于候选规划，不代表当前版本已经提供或确定交付：

### 面试准备闭环 V1

若后续启动，建议作为**投递管理中单个岗位的二级能力**，从“面试中”的投递记录进入，而不是新增独立一级模块。这样可以直接复用该岗位的 JD、简历、分析报告和跟进记录，避免产品导航继续膨胀。

候选范围：

- 基于 JD、简历和岗位分析生成高概率面试问题。
- 为问题关联可用经历证据、回答框架和证据边界。
- 支持模拟追问、回答反馈和薄弱项复练。
- 将准备结果和下一步行动回写到对应投递记录。

### 稳定性与体验优化

- 优化后端冷启动和高延迟接口。
- 增强上游 AI 服务瞬时异常的重试与降级能力。
- 补充自动化冒烟测试和发布检查。
- 根据真实使用反馈决定是否启动新的功能模块。

## 技术栈

- 前端：React、Vite、CSS、lucide-react
- 后端：FastAPI、Python
- 数据库：Supabase PostgreSQL（支持 SQLite fallback）
- AI：兼容 OpenAI API 协议的模型服务
- 部署：静态 Web 站点 + 函数服务
